# Mission: Monetize the Vocabulary Deck Generator

## Why
Make the existing web app publicly usable and earn revenue through Google AdSense without creating uncontrolled API costs or exposing the home server unnecessarily.

## Success looks like
- Explain how AdSense code, site review, and ad placement fit into the current app.
- Safely add and verify AdSense after the site is public and approved.

## Constraints
- App is a FastAPI backend serving a static frontend; server runs at home 24/7.
- Prefer low-cost, minimal changes; Gemini API usage can incur charges.

## Out of scope
- Building a new website or choosing a different ad network.
